# MTG decks (Reality Fracture / FRA)

Photos of our Reality Fracture cards, 40-card decks built from them, and a GitHub Pages site that shows the decks.

There are two separate collections, each in its own folder:

- [`dad/`](dad/): Dad's cards and decks. See [`dad/README.md`](dad/README.md) for the card photo index.
- [`son/`](son/): Son's cards and decks (just set up, no decks yet). See [`son/README.md`](son/README.md).

`index.html` is the deck page, with Dad and Son as the top tabs and each person's decks as the tabs underneath. It is generated by `python3 tools/build_site.py`. See [`AGENTS.md`](AGENTS.md) for the full layout and how to add a deck.
