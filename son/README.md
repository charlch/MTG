# Son's MTG collection (Reality Fracture / FRA)

Photos of Son's FRA cards, one image per card, plus the original photos they were cut from. Nothing has been added yet.

- `cards/` has one image per card. Foil and non-foil copies are marked in the file name.
- `tokens-and-extras/` has the tokens, emblems and counter sticker sheets.
- `photos/` has the original photos, in the order they were taken.
- `thumbs/` has the small versions used by the page (made by `tools/build_site.py`).
- `decks/` has one `.dck` file per deck, and `decks.py` has the data for the deck page.

This mirrors `dad/`. See [`../AGENTS.md`](../AGENTS.md) for how decks are added.
