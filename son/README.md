# Son's MTG collection (Reality Fracture / FRA)

Photos of Son's FRA cards, one image per card, plus the original photos they were cut from.

- `cards/` has one image per card (56 cards). Foil and non-foil copies would be marked in the file name.
- `tokens-and-extras/` has the tokens (3).
- `photos/` has the 15 original photos, in the order they were taken (`photo-01.jpg` to `photo-15.jpg`).
- `thumbs/` has the small versions used by the page (made by `tools/build_site.py`).
- `decks/` has one `.dck` file per deck, and `decks.py` has the data for the deck page.

This mirrors `dad/`. See [`../AGENTS.md`](../AGENTS.md) for how decks are added.

## Cards cut off in the photo

These cards ran off the edge of the photo, so their image is missing a strip on one side. Re-photograph them if you want a full image: Blossom-Blessed Angel, Fblthp, Impossibly Lost, Emergency Phytomedic, Marwyn, the Clearcutter, Theorix Annex, Ruric Thar, Magecrusher, No Admittance, Flesh Duplicate, Lyra, Archangel of Dawn, Cadet token, Eardrum Rattler, Predictive Preparations, Living Library, Konstrari Charm, Way of the Mentor, Primal Witchstalker.
